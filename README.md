# Motorized IRON-MAN (MK7) Helmet.

I have made this project in 2024 for fun, learning and my son.
After 2 years, I decided to make an assembly guide and publish the project on MakerWorld.

3D design made with Plasticity from pictures.
PCB design made with KICAD
Software and PCB are available on Github : Iron-Man-Helmet
